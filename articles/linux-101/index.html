Linux 101 for Noobs (Like Me): Getting Comfortable with the Basics

TL;DR

  • Linux directories = folders.
  • mkdir to create, cd to move, .. to go back.
  • ls to see contents, cat to view files.
  • cp, mv, rm to manage files.
  • rm -r = flamethrower for directories, use carefully.
  • clear to tidy the terminal.
  • Next up: Oh My Zsh for a smarter, friendlier shell.

When you first open the terminal, it can feel like staring into a void. No buttons, no menus, just a blinking cursor waiting for you to type something clever. But here’s the secret: you don’t need to know hundreds of commands to get started. Just a small handful will help you move around, manage files, and peek inside them. Once you learn these, the terminal starts feeling less like a dark cave and more like your personal command centre.

And I promise you this: once you get used to it, you’ll be hooked. Before long, you’ll be zipping around the terminal with your eyes closed!

Let’s go through the essentials.

Navigation: Moving Around the System

Think of your computer as a giant filing cabinet. You’re just moving from one drawer (directory) to another.

pwd - print working directory: shows where you are right now. 

pwd

“On Linux, a directory is the same thing as a folder on Windows or macOS. The word is just different.”

Make Directory!

We need a directory to put our projects in it! So let’s make a directory! 

mkdir projects

Yes, it is time to check that the directory exists! For this we will use List! (see what’s inside the current directory)

List! ls 

ls

Change Directory!

cd - change directory: lets you move to a different folder. 

cd projects

We are slowly slowly coming!

Create first file via Vim!

Creating our first file via Vim! 

vim hello.py

Here is our first file!

Let’s fill it!

Press i to switch into insert mode.

Type this line: 

print("Hello from Vim!")

Press Esc to leave insert mode.

Type :wq and press Enter (write and quit).

Looking Inside Your File: cat

Let’s check that our file really exists and has content. Use the cat command (short for concatenate) to print the whole file to the terminal: 

cat hello.py

You should see:

Yes you did it! 🎊 You created your first file via Vim!

Let’s Backup Our New File!

Copy (cp): make a duplicate of a file. 

cp hello.py hello_backup.py

Try ls to check your backup exists!

Yup! It’s there!

Deleting Files! rm

Sometimes you don’t need a file anymore. The command for removing it is rm (short for remove): 

rm hello_backup.py

That deletes the file permanently. No recycle bin, no “Are you sure?” pop-up. Once it’s gone, it’s gone.

Try running ls afterwards to see that hello_backup.py has disappeared.

Pro tip: start by removing copies or files you don’t care about, so you don’t accidentally delete your hard work.

Going Back Up - Parent Directory!

Right now you’re inside your projects directory. To step one level back (up to your home folder), use: 

cd ..

The two dots mean “the parent directory.”

Removing a Directory: rmdir

If you try to remove projects while it still has files, Linux will complain: 

rmdir projects
rmdir: failed to remove 'projects': Directory not empty

That’s because rmdir only works on empty folders. To delete a folder and everything inside it, you need: 

rm -r projects

The -r means recursive, which is just a fancy way of saying “go inside, wipe out everything, then remove the folder too.”

This is the flamethrower of Linux commands: powerful, fast, and absolutely no undo button. Use it carefully, or you’ll burn down the wrong directory! 🔥🔥

Noob to noob advice: always double check with ls!

Clearing the Terminal

After all that experimentation, creating files, copying, deleting, surviving Vim, your terminal might look a little messy. To clear everything from view without touching your files, just type: 

clear

And voilà! A clean slate. The commands you ran are still in history, but your terminal looks nice and tidy, ready for the next adventure.

It’s like wiping your whiteboard before starting a new lesson. Your workspace feels fresh, and you can focus without distractions.

Wrapping Up

Congratulations! You’ve navigated directories, created and peeked inside files, copied and deleted them, and even wielded the flamethrower with rm -r. You’ve cleared the chaos with clear and survived Vim without panic.

Linux 101 Cheat Sheet 

pwd                     # show current directory
mkdir projects          # make a new folder
cd projects             # move into a folder
cd ..                   # move back up
ls                      # list files
vim hello.py            # create/edit file
cat hello.py            # view file content
cp hello.py backup.py   # copy file
mv backup.py archive.py # move/rename file
rm archive.py           # delete file
rm -r projects          # delete folder recursively (⚠ flamethrower! 🔥)
clear                   # clear the terminal
